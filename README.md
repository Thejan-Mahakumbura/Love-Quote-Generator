# Love Quotes Generator

A single-file, responsive HTML/CSS/JavaScript landing page and quote generator.

## Run
Open `index.html` in a modern browser.

## Included
- 100+ English quotes plus Spanish, French, Hindi and Portuguese quote sets
- Unlimited random generation with no immediate repeats
- Copy to clipboard with toast confirmation
- Watermark-free PNG export
- Floral, Minimal, Sunset, Dark Romantic and Paper templates
- 1:1, 9:16, 16:9 and 2:3 export ratios
- Heart-rain animation with reduced-motion support
- Language/template/ratio persistence via localStorage
- Responsive mobile-first UI
- SEO/Open Graph metadata
